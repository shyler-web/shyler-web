## Featured work

### ScriptForge

[![ScriptForge demo](https://shyler-web.github.io/scriptforge-handwriting/docs/demo/scriptforge-demo-poster.webp)](https://shyler-web.github.io/scriptforge-handwriting/)

Plain text + LaTeX + diagrams → hand-drawn notebook pages and multi-page PDFs. Browser-native, offline, zero dependencies, with a declarative `[sketch]` engine and an MCP server for coding agents.

`JavaScript` `Canvas` `LaTeX` `MCP` `Offline`
